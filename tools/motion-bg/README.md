# motion-bg — генератор фонового видео

Отсюда берутся `assets/motion.mp4` (фон сайта) и `assets/motion-poster.jpg` (постер — показывается,
пока видео грузится). Видео полностью процедурное: один GLSL-шейдер, никаких стоков.

Стиль — «ночная сакура × неон»: почти чёрный фиолетовый фон, шёлковые светящиеся ленты
(розовый `#ff3d9a` / `#ff8cc6`, фиолетовый `#9b7bff`), «затмение»-ореол за 3D-героем (≈70% ширины),
занавес полярного сияния справа сверху, боке на разной глубине, пара размытых лепестков.
Лево-центр (там карточка) специально тёмный и спокойный.

## Файлы

| файл | что это |
|---|---|
| `motion.frag` | фрагментный шейдер (WebGL2 / GLSL ES 3.00). Внутри — 4D simplex noise из [webgl-noise](https://github.com/ashima/webgl-noise) (MIT) |
| `render.cjs` | рендерит кадры в PNG через headless Chromium (Playwright, WebGL через SwiftShader) |
| `encode.sh` | склеивает кадры в H.264 MP4 и делает постер из кадра 0 |

## Как перерендерить

Нужны Node.js, Playwright с Chromium (`npm i -g playwright && npx playwright install chromium`) и ffmpeg.

```bash
cd tools/motion-bg

# 1) кадры: 1920x1080, 30 fps, 12 секунд = 360 кадров (на 4 ядрах ≈ 10–15 минут)
node render.cjs --out /tmp/motion-frames --w 1920 --h 1080 --fps 30 --seconds 12 --workers 3

# 2) видео + постер → ../../assets/
./encode.sh /tmp/motion-frames 30 20
```

- Рендер можно прервать и запустить снова — уже готовые кадры пропускаются (`--overwrite` — перерисовать все).
- Быстрый черновик: `--w 960 --h 540`. Отдельные кадры: `--frames 0,90,180`.
- Третий аргумент `encode.sh` — CRF: меньше = качественнее и тяжелее. Бюджет файла — до ~7 МБ.

## Почему луп бесшовный

Всё движение — функция фазы `θ = 2π·t/T`:

- шум берётся 4D: `snoise(x, y, r·cos θ, r·sin θ)` — за оборот θ он возвращается в ту же точку;
- волны изгиба и перекрута лент, блик на кольце, «дыхание» — синусы с **целыми** частотами по θ;
- боке и лепестки живут циклами, которые укладываются в луп целое число раз, и рождаются/гаснут с нулевой яркостью;
- световая волна проходит по диагонали раз за луп и «перепрыгивает» к началу, когда она за кадром.

Кадр N (не рендерится) совпадает с кадром 0, поэтому `loop` у `<video>` не даёт скачка.
Проверка: `node render.cjs --out /tmp/chk --frames 360` и сравнить с кадром 0 — разница ≤ 1/255.

## Что можно крутить в `motion.frag`

- `hero` — где ореол (по умолчанию под 3D-героем, ≈70% ширины); `card` и `calm` — тёмная зона под карточкой.
- `Ribbon A/B/C/D` — ленты: положение, угол, ширина, амплитуда, частоты волн (`m`, `tm` — только целые!).
- `phase = uPhase + 0.25` — какой момент лупа попадёт в кадр 0 / постер.
- Зерно в видео не запекаем (оно убивает сжатие) — его добавляет CSS-слой `.grain`.
  Против бэндинга в шейдере стоит статичный дизеринг (одинаковый в каждом кадре).
